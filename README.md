# Hyundai Kona asking prices

Interactive chart of asking prices from public Yad2 listings for non-electric Hyundai Kona, model year 2020 onward.

Snapshot: 8.10.2026. Personal analysis, not affiliated with Yad2. Mileage is shown as a km range taken from Yad2's own km filter, so it is a band (for example 30-60K km), not the exact odometer reading. 5 listings did not appear in any range and are marked unknown. Asking prices are not sale prices. The table links to the public Yad2 ads, which may no longer be available.
